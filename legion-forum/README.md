# LEGION — форум CSS v34 Bhop

Настоящий форум (не клон GameBanana): список разделов, темы с сообщениями, ответы
с разметкой, «Спасибо», цитирование, удаление своих сообщений, поиск по форуму,
страница создания темы, раздел файлов с загрузкой и скачиванием, правила и FAQ.

Тёмная тема, акцент — лаймовый (`#a4e336`). Картинок нет, только текст, иконки-эмодзи
и CSS-графика.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Открыть `http://localhost:8080/` (занят порт — `.\serve.ps1 -Port 8090`).
Можно просто открыть `index.html` двойным кликом — всё работает, но браузер может
ограничить IndexedDB на `file://`, тогда файлы перейдут в localStorage с лимитом 3 МБ.

## Как это работает

Бэкенда нет. Темы, ответы, удаления, счётчики «Спасибо» и скачиваний хранятся в
`localStorage` (ключ `legion.forum.v1`), файлы — в IndexedDB (`legion_files`), с
фолбэком на localStorage и память. Текущий режим показан в подвале страницы файлов.

Созданные темы и ответы переживают перезагрузку и сразу появляются в списках —
счётчики тем и сообщений пересчитываются на лету. Ответ в «сид»-теме переносит её
в пользовательские данные, поэтому не теряется.

## Загрузка файлов

1. <a href="files.html">Раздел файлов</a> → перетащи файл в зону загрузки или нажми «Выбрать файлы».
2. Файл получит метку **мой** и кнопки **↓ Скачать** / **Удалить**.
3. **↓ Скачать** отдаёт файл байт в байт и увеличивает счётчик скачиваний.

Записи с меткой **демо** — часть контента форума. Реальных сборок в проекте нет,
поэтому вместо них скачивается текстовая заглушка `.demo.txt`.

## Что менять

- разделы, темы, файлы, пользователи — `assets/data.js`;
- цвета и отступы — переменные в начале `assets/style.css`;
- имя пользователя, который создаёт темы и загружает файлы, — `L_FORUM.you`
  и в шапке каждой страницы (`login`);
- лимит файлов в localStorage — `LS_MAX` в `assets/files.js`.
